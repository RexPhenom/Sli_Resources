Sign in to manage your site.

Changes you make here are saved straight to your website and go live in about a minute. Connect once with a private GitHub key.

  1. Open GitHub’s key page (sign in if asked).
  2. Name it SLI admin. Set expiry to 1 year.
  3. Under Repository access choose Only select repositories, then pick Sli_Resources.
  4. Under Permissions → Repository permissions set Contents to Read and write.
  5. Tap Generate token, copy it, and paste it below.

Your key stays on this device and is sent only to GitHub. It is never saved in the website’s code.
